# NH Solutions: Image Prompts for ChatGPT

These prompts generate all 47 images for the NH Solutions website. The look is premium product-prototype photography: realistic UI on devices or floating cards, soft studio light, calm palette. No glowing brains, robots, neon or stock-AI clichés.

## How to use

1. Open a new ChatGPT chat with the image model.
2. Paste the **Master style** below once, first.
3. Paste each prompt, one per image. Set the aspect ratio given (4:5, 16:9 or 1:1). If ChatGPT ignores it, add "Aspect ratio 16:9" to the prompt.
4. Download the image, convert or save it as `.jpg`, and rename it to the **exact filename** shown.
5. Save every file into `nh-solutions/assets/img/`.
6. Tell Claude when you are done and it will wire them in.

If an image looks too glossy, too "AI", or has readable text, regenerate with: "More restrained, more matte, fewer elements, all text as blurred placeholder lines."

## Master style (paste first, once)

```text
For this whole session, generate images in one consistent art direction: premium product-prototype photography, like a Dribbble or Behance case-study presentation or Apple-style product photography. Show realistic UI screens on devices (laptop, phone, tablet, monitor) or floating UI cards. Soft natural studio light, matte surfaces, subtle soft shadows, generous negative space, shallow depth of field. Palette: off-white, soft lavender and warm grey, with small accents of indigo (#3D3BF3), violet (#9B2CF0) and coral (#FF6B4A). Any UI text must be minimal, blurred or abstract placeholder lines, never readable. Strictly avoid: glowing brains, robots, neon, holograms, circuit boards, lens flares, fake 3D text, logos, readable brand names, watermarks, stock-photo clichés. People, where requested, are candid Indian professionals in natural light, editorial look, not posed. Do not add captions. Confirm and wait for my first prompt.
```
